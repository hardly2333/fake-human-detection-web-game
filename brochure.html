一、关于检测工具

本营地位于旧文明遗址之上。先民遗留了一批被称为"人体工学椅"的奇物——它们依照人类骨骼结构设计，能精准贴合坐骨、腰椎与肩颈曲线。旧文献记载，这种椅子在数千年前曾是办公场所的标配。

伪人由异质捏造而成，虽能模仿人类外貌，却无法理解椅子的逻辑。它们要么把椅子调得过高导致双脚悬空，要么让坐垫塌陷、扶手异形、靠背断裂——因为异质没有骨骼，自然不知道骨骼需要什么支撑。

因此，椅子成了最可靠的检测工具。一个能正确使用椅子的人是可信的；一个坐姿违背人体工学的人，绝非人类。

二、你的职责

  1. 核验比照：每位归队队员需出示其档案照。调取其归来后的实拍影像，拖动对比滑块，逐一比对坐姿与椅况。
  2. 判定异常：依据本手册背面的《新人检测指南》所列标准，凡出现椅子异常或坐姿违背人体工学原理者，即视为伪人。
  3. 执行隔离：将判定为伪人的队员标记后上报。正确识别者将被隔离处理，无辜者不得受牵连。

⚠ 对真人误判将影响你的门卫考评。请谨慎判断，善用本手册提供的知识点。

合格坐姿 · 三个 90° 原则

90°
躯干与大腿
臀坐最深处，腰部紧贴椅背，不前倾不下滑
90°
膝关节
双脚平稳触地，大腿平行地面，不悬空不垫脚
90°
肘关节
双肩自然下沉，前臂平放扶手，不耸肩不悬臂

+ 显示器顶端与视线平行，不低头不仰头

椅子结构速查

部件合格标志异常警报
坐垫 平整、有弹性 塌陷、破洞 → 劣质网布或海绵失效，无法承托体重
靠背 稳固、贴合腰部 断裂后倒 → 腰部悬空无支撑，极易导致腰椎损伤

椅腿 四脚平稳着地 扭曲、不稳 → 底盘损坏，有倾覆风险
气压棒 无裂纹、无异响 裂纹、漏气 → 极度危险！须立即隔离

安全认证标志

合格气压棒认证：SGS  ·  TUV  ·  BIFMA
安全级别：Class 3 或 Class 4 以上
选购参考：大体重（≥80kg）选高密度海绵 / 高弹力网布；小个子注意最低坐高
试坐重点：腰部是否悬空？大腿是否受压？肩膀是否自然下沉？
记住：没有任何坐姿适合保持一整天 · 每隔 45-60 分钟起来活动
